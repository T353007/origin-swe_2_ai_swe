# Error Handling and Retries

## Overview

LLM APIs can fail for many reasons: rate limits, network issues, server errors, timeouts. Robust error handling with retries is essential for production systems.

## Main Content

### Common Error Types

**Rate Limit Errors:**
- Too many requests
- Need to wait before retrying
- Often include retry-after header

**Timeout Errors:**
- Request took too long
- Network issues
- Model overloaded

**API Errors:**
- Invalid requests
- Authentication failures
- Service unavailable

**Quota Exceeded:**
- Out of tokens/credits
- Billing issues
- Requires different handling

### Basic Error Handling

```python
from openai import OpenAI, RateLimitError, APIError
import time

client = OpenAI()

def call_llm_with_error_handling(prompt: str):
    """Call LLM with basic error handling."""
    try:
        response = client.chat.completions.create(
            model="gpt-4",
            messages=[{"role": "user", "content": prompt}],
            timeout=30.0
        )
        return response.choices[0].message.content
    except RateLimitError as e:
        print(f"Rate limit hit: {e}")
        # Could implement retry logic here
        raise
    except APIError as e:
        print(f"API error: {e}")
        raise
    except Exception as e:
        print(f"Unexpected error: {e}")
        raise
```

### Retry with Exponential Backoff

```python
import time
import random
from typing import Callable, TypeVar

T = TypeVar('T')

def retry_with_backoff(
    func: Callable[[], T],
    max_retries: int = 3,
    initial_delay: float = 1.0,
    max_delay: float = 60.0,
    exponential_base: float = 2.0
) -> T:
    """Retry function with exponential backoff."""
    delay = initial_delay
    
    for attempt in range(max_retries):
        try:
            return func()
        except RateLimitError as e:
            if attempt == max_retries - 1:
                raise
            
            # Check for retry-after header
            retry_after = getattr(e, 'retry_after', None)
            if retry_after:
                delay = retry_after
            else:
                delay = min(delay * exponential_base, max_delay)
            
            # Add jitter to avoid thundering herd
            jitter = random.uniform(0, delay * 0.1)
            time.sleep(delay + jitter)
            
        except (APIError, TimeoutError) as e:
            if attempt == max_retries - 1:
                raise
            time.sleep(delay)
            delay = min(delay * exponential_base, max_delay)
    
    raise Exception("Max retries exceeded")

# Usage
def get_completion():
    return client.chat.completions.create(
        model="gpt-4",
        messages=[{"role": "user", "content": "Hello"}]
    )

result = retry_with_backoff(get_completion)
```

### Using Tenacity Library

```python
from tenacity import (
    retry,
    stop_after_attempt,
    wait_exponential,
    retry_if_exception_type
)
from openai import RateLimitError, APIError

@retry(
    stop=stop_after_attempt(3),
    wait=wait_exponential(multiplier=1, min=4, max=60),
    retry=retry_if_exception_type((RateLimitError, APIError, TimeoutError))
)
def call_llm_robust(prompt: str):
    """Call LLM with automatic retries."""
    response = client.chat.completions.create(
        model="gpt-4",
        messages=[{"role": "user", "content": prompt}],
        timeout=30.0
    )
    return response.choices[0].message.content
```

### Graceful Degradation

```python
def call_llm_with_fallback(prompt: str):
    """Try multiple models with fallback."""
    models = ["gpt-4", "gpt-3.5-turbo", "gpt-3.5-turbo"]
    
    for model in models:
        try:
            response = client.chat.completions.create(
                model=model,
                messages=[{"role": "user", "content": prompt}],
                timeout=10.0
            )
            return response.choices[0].message.content
        except Exception as e:
            print(f"Failed with {model}: {e}")
            continue
    
    # Final fallback
    return "I'm sorry, I'm having trouble right now. Please try again later."
```

## Code Examples

Complete error handling class:

```python
from openai import OpenAI, RateLimitError, APIError, APITimeoutError
import time
import random
from typing import Optional

class RobustLLMClient:
    def __init__(
        self,
        max_retries: int = 3,
        initial_delay: float = 1.0,
        max_delay: float = 60.0
    ):
        self.client = OpenAI()
        self.max_retries = max_retries
        self.initial_delay = initial_delay
        self.max_delay = max_delay
    
    def call(
        self,
        prompt: str,
        model: str = "gpt-4",
        fallback_models: Optional[list] = None
    ) -> str:
        """Call LLM with comprehensive error handling."""
        models = [model] + (fallback_models or [])
        
        for model_name in models:
            for attempt in range(self.max_retries):
                try:
                    response = self.client.chat.completions.create(
                        model=model_name,
                        messages=[{"role": "user", "content": prompt}],
                        timeout=30.0
                    )
                    return response.choices[0].message.content
                    
                except RateLimitError as e:
                    if attempt < self.max_retries - 1:
                        delay = self._calculate_delay(e, attempt)
                        time.sleep(delay)
                        continue
                    else:
                        if model_name != models[-1]:
                            break  # Try next model
                        raise
                
                except (APIError, APITimeoutError) as e:
                    if attempt < self.max_retries - 1:
                        time.sleep(self._calculate_delay(None, attempt))
                        continue
                    else:
                        if model_name != models[-1]:
                            break  # Try next model
                        raise
        
        raise Exception("All models and retries exhausted")
    
    def _calculate_delay(self, error: Optional[Exception], attempt: int) -> float:
        """Calculate retry delay."""
        if error and hasattr(error, 'retry_after'):
            return error.retry_after
        
        delay = self.initial_delay * (2 ** attempt)
        delay = min(delay, self.max_delay)
        # Add jitter
        jitter = random.uniform(0, delay * 0.1)
        return delay + jitter

# Usage
client = RobustLLMClient()
response = client.call(
    "Explain RAG",
    model="gpt-4",
    fallback_models=["gpt-3.5-turbo"]
)
```

## Common Mistakes

1. **No retries**: Single failure breaks the system
2. **No backoff**: Retries too quickly, still rate limited
3. **No jitter**: All clients retry simultaneously
4. **Ignoring retry-after**: Not respecting API headers
5. **No fallbacks**: Single model failure breaks system
6. **Infinite retries**: Can cause cost explosions
7. **Not logging errors**: Can't debug production issues
