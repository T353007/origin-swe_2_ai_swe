# Understanding Embeddings

## Overview

Embeddings are numerical representations of text that capture semantic meaning. They're the foundation of semantic search, RAG, and many AI applications.

## Main Content

### What Are Embeddings?

Embeddings convert text into high-dimensional vectors (arrays of numbers) where similar texts have similar vectors. For example:
- "dog" and "puppy" → similar vectors
- "dog" and "airplane" → different vectors

### How Embeddings Work

1. Text → Tokenization
2. Tokens → Model processing
3. Model output → Fixed-size vector (e.g., 1536 dimensions)

### Using Embeddings

```python
from openai import OpenAI

client = OpenAI()

def get_embedding(text: str, model: str = "text-embedding-3-small"):
    response = client.embeddings.create(
        input=text,
        model=model
    )
    return response.data[0].embedding

# Example
embedding = get_embedding("Hello, world!")
print(f"Embedding dimension: {len(embedding)}")
```

### Semantic Similarity

Calculate similarity using cosine similarity:

```python
import numpy as np

def cosine_similarity(vec1: list, vec2: list) -> float:
    vec1 = np.array(vec1)
    vec2 = np.array(vec2)
    return np.dot(vec1, vec2) / (np.linalg.norm(vec1) * np.linalg.norm(vec2))

# Example
text1 = "I love programming"
text2 = "I enjoy coding"
text3 = "I like cooking"

emb1 = get_embedding(text1)
emb2 = get_embedding(text2)
emb3 = get_embedding(text3)

print(f"Similarity 1-2: {cosine_similarity(emb1, emb2)}")  # High
print(f"Similarity 1-3: {cosine_similarity(emb1, emb3)}")  # Low
```

## Code Examples

Finding similar documents:

```python
def find_most_similar(query: str, documents: list[str], top_k: int = 3):
    query_embedding = get_embedding(query)
    doc_embeddings = [get_embedding(doc) for doc in documents]
    
    similarities = [
        cosine_similarity(query_embedding, doc_emb) 
        for doc_emb in doc_embeddings
    ]
    
    # Get top K most similar
    top_indices = np.argsort(similarities)[-top_k:][::-1]
    return [(documents[i], similarities[i]) for i in top_indices]
```

## Common Mistakes

1. **Not normalizing embeddings**: Some operations require normalized vectors
2. **Wrong model choice**: Different models for different use cases
3. **Batch size too large**: API rate limits
4. **Not caching embeddings**: Regenerating the same embeddings wastes money
