# Setting Up Your Development Environment

## Overview

A proper development environment is crucial for AI engineering. This lesson covers setting up Python, virtual environments, API keys, and essential tools.

## Main Content

### Python Setup

Use Python 3.9+ for best compatibility with AI libraries:

```bash
# Check Python version
python --version

# Create virtual environment
python -m venv venv

# Activate (macOS/Linux)
source venv/bin/activate

# Activate (Windows)
venv\Scripts\activate
```

### Essential Packages

```bash
pip install openai anthropic langchain langsmith
pip install tiktoken  # Token counting
pip install python-dotenv  # Environment variables
```

### API Key Management

**Never commit API keys to git!**

1. Create a `.env` file:
```bash
OPENAI_API_KEY=sk-...
ANTHROPIC_API_KEY=sk-ant-...
```

2. Use `python-dotenv`:
```python
from dotenv import load_dotenv
import os

load_dotenv()
api_key = os.getenv("OPENAI_API_KEY")
```

3. Add `.env` to `.gitignore`:
```
.env
.env.local
*.env
```

## Code Examples

Complete setup example:

```python
# requirements.txt
openai>=1.0.0
python-dotenv>=1.0.0
tiktoken>=0.5.0

# main.py
import os
from dotenv import load_dotenv
import openai

load_dotenv()
openai.api_key = os.getenv("OPENAI_API_KEY")

# Test connection
response = openai.ChatCompletion.create(
    model="gpt-3.5-turbo",
    messages=[{"role": "user", "content": "Hello!"}]
)
print(response.choices[0].message.content)
```

## Common Mistakes

1. **Committing API keys**: Always use `.env` files and `.gitignore`
2. **Not using virtual environments**: Leads to dependency conflicts
3. **Outdated packages**: AI libraries change rapidly; keep updated
4. **Hardcoding secrets**: Use environment variables or secrets management
