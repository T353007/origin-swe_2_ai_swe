# Production Agent Patterns

> **💡** "Moving agents from prototype to production is like moving a pet hamster to the wild - suddenly you realize it needs guards against predators, food management, and a way to find its way home. Production agents need loop prevention, cost controls, error handling, and monitoring. Without these, your agent will either cost you thousands or get stuck in an infinite loop trying to find the answer to life, the universe, and everything." - AI Engineering Best Practice

## Overview

Building agents that work in production requires handling challenges that don't appear in prototypes: infinite loops, token cost explosions, tool failures, unpredictable behavior, monitoring, and observability. This lesson covers production-ready patterns and strategies for deploying reliable, cost-effective, and maintainable agents.

The difference between a prototype agent and a production agent is the difference between "it works on my machine" and "it works for thousands of users, handles errors gracefully, stays within budget, and provides visibility into its behavior." Production agents need safeguards, monitoring, and robust error handling.

## Production Challenges

Agents face unique challenges in production that traditional software doesn't:

### 1. Infinite Loops

Agents can get stuck repeating the same actions or reasoning endlessly, consuming resources and failing to complete tasks.

**Common causes:**
- Tasks with no solution (agent keeps trying)
- Circular reasoning patterns
- Repeated tool calls that don't progress
- No loop detection or iteration limits

**Impact:**
- Wastes tokens (hundreds of thousands, costing hundreds of dollars)
- Degrades user experience (slow or unresponsive)
- Consumes compute resources
- Can cause system failures

### 2. Token Cost Explosion

Agent runs can consume massive amounts of tokens, leading to unexpectedly high costs.

**Common causes:**
- Long conversation histories
- Multiple tool calls accumulating context
- No token budgets or limits
- Inefficient prompt design
- No conversation summarization

**Impact:**
- Costs can be 10-100x higher than expected
- Budget overruns
- Unpredictable pricing
- Can make product unprofitable

### 3. Tool Failures

Tools can fail for many reasons: network issues, API errors, timeouts, invalid inputs.

**Common causes:**
- Network timeouts
- API rate limits
- Invalid tool arguments from LLM
- External service failures
- Authentication errors

**Impact:**
- Agent stops working
- Poor user experience
- No error recovery
- Production incidents

### 4. Unpredictable Behavior

Agents can behave unpredictably, making different decisions for similar inputs.

**Common causes:**
- Probabilistic LLM outputs
- Temperature settings too high
- Inconsistent tool descriptions
- Ambiguous user inputs

**Impact:**
- Inconsistent user experience
- Difficult to debug
- Hard to reproduce issues
- Quality varies

### 5. Lack of Observability

Without proper monitoring, you can't understand what agents are doing or why they fail.

**Common causes:**
- No logging of agent decisions
- No metrics on tool usage
- No visibility into token consumption
- No error tracking

**Impact:**
- Can't debug production issues
- Can't optimize costs
- Can't improve agent behavior
- No visibility into failures

## Loop Prevention

Preventing infinite loops is critical for production agents. Implement multiple layers of protection.

### Loop Detection Strategies

**1. Iteration Limits**

Simple but essential: set a maximum number of iterations per agent run.

```python
class LoopPrevention:
    def __init__(self, max_iterations: int = 15, max_execution_time: int = 300):
        self.max_iterations = max_iterations
        self.max_execution_time = max_execution_time
        self.iteration_count = 0
        self.start_time = None
    
    def check_limits(self) -> tuple[bool, str]:
        """Check if agent has exceeded limits."""
        if self.start_time is None:
            self.start_time = time.time()
        
        # Check iteration limit
        if self.iteration_count >= self.max_iterations:
            return True, f"Max iterations ({self.max_iterations}) reached"
        
        # Check execution time limit
        elapsed = time.time() - self.start_time
        if elapsed > self.max_execution_time:
            return True, f"Max execution time ({self.max_execution_time}s) exceeded"
        
        return False, ""
    
    def increment(self):
        """Increment iteration counter."""
        self.iteration_count += 1
```

**2. Action Repetition Detection**

Detect when the agent repeats the same action multiple times.

```python
class ActionRepetitionDetector:
    def __init__(self, repetition_threshold: int = 3):
        self.repetition_threshold = repetition_threshold
        self.recent_actions = []
        self.action_counts = {}
    
    def check_repetition(self, current_action: str) -> tuple[bool, str]:
        """Check if action is being repeated too often."""
        self.recent_actions.append(current_action)
        
        # Keep only recent actions (last 10)
        if len(self.recent_actions) > 10:
            self.recent_actions.pop(0)
        
        # Count occurrences in recent actions
        recent_count = self.recent_actions.count(current_action)
        
        if recent_count >= self.repetition_threshold:
            return True, f"Action '{current_action}' repeated {recent_count} times"
        
        # Check for same action in last N actions
        if len(self.recent_actions) >= self.repetition_threshold:
            last_n = self.recent_actions[-self.repetition_threshold:]
            if len(set(last_n)) == 1:  # All same
                return True, f"Same action '{current_action}' {self.repetition_threshold} times in a row"
        
        return False, ""
```

**3. Circular Pattern Detection**

Detect when the agent cycles through a sequence of actions.

```python
class CircularPatternDetector:
    def __init__(self, pattern_length: int = 3):
        self.pattern_length = pattern_length
        self.action_history = []
    
    def check_circular_pattern(self, current_action: str) -> tuple[bool, str]:
        """Check for circular action patterns."""
        self.action_history.append(current_action)
        
        # Need enough history to detect patterns
        if len(self.action_history) < self.pattern_length * 2:
            return False, ""
        
        # Check if last pattern_length actions repeat
        recent_pattern = self.action_history[-self.pattern_length:]
        previous_pattern = self.action_history[-self.pattern_length * 2:-self.pattern_length]
        
        if recent_pattern == previous_pattern:
            return True, f"Circular pattern detected: {recent_pattern}"
        
        return False, ""
```

**4. Progress Tracking**

Track whether the agent is making progress toward its goal.

```python
class ProgressTracker:
    def __init__(self):

        self.no_progress_threshold = 5
    
    def check_progress(self, current_state: dict) -> tuple[bool, str]:

        # Keep only recent states
        if len(self.states) > self.no_progress_threshold:
            self.states.pop(0)
        
        # Check if state has changed (simplified - in production use more sophisticated comparison)
        if len(self.states) >= self.no_progress_threshold:
            recent_states = self.states[-self.no_progress_threshold:]
            if len(set(str(s) for s in recent_states)) == 1:
```

### Complete Loop Prevention System

Combine all strategies for robust loop prevention:

```python
import time
from typing import Dict, List, Tuple

class ProductionLoopPrevention:
    """Complete loop prevention system for production agents."""
    
    def __init__(
        self,
        max_iterations: int = 15,
        max_execution_time: int = 300,
        repetition_threshold: int = 3,
        pattern_length: int = 3
    ):
        self.max_iterations = max_iterations
        self.max_execution_time = max_execution_time
        self.repetition_threshold = repetition_threshold
        self.pattern_length = pattern_length
        
        self.iteration_count = 0
        self.start_time = None
        self.recent_actions: List[str] = []
        self.action_history: List[str] = []
        self.states: List[Dict] = []
    
    def check_all(self, current_action: str, current_state: Dict = None) -> Tuple[bool, str]:
        """Check all loop prevention mechanisms."""
        if self.start_time is None:
            self.start_time = time.time()
        
        self.iteration_count += 1
        self.recent_actions.append(current_action)
        self.action_history.append(current_action)
        if current_state:
            self.states.append(current_state)
        
        # Check iteration limit
        if self.iteration_count > self.max_iterations:
            return True, f"Max iterations ({self.max_iterations}) reached"
        
        # Check execution time
        elapsed = time.time() - self.start_time
        if elapsed > self.max_execution_time:
            return True, f"Max execution time ({self.max_execution_time}s) exceeded"
        
        # Check repetition
        if len(self.recent_actions) >= self.repetition_threshold:
            last_n = self.recent_actions[-self.repetition_threshold:]
            if len(set(last_n)) == 1:
                return True, f"Action '{current_action}' repeated {self.repetition_threshold} times"
        
        # Check circular pattern
        if len(self.action_history) >= self.pattern_length * 2:
            recent_pattern = self.action_history[-self.pattern_length:]
            previous_pattern = self.action_history[-self.pattern_length * 2:-self.pattern_length]
            if recent_pattern == previous_pattern:
                return True, f"Circular pattern: {recent_pattern}"
        
        # Check progress (simplified)
        if len(self.states) >= 5:
            recent_states = self.states[-5:]
            if len(set(str(s) for s in recent_states)) == 1:
                return True, "No progress detected"
        
        return False, ""
    
    def reset(self):
        """Reset state (for new agent run)."""
        self.iteration_count = 0
        self.start_time = None
        self.recent_actions = []
        self.action_history = []
        self.states = []
```

## Cost Management

Agent runs can be expensive. Implement cost tracking and budgets to prevent budget overruns.

### Cost Tracking

Track token usage and calculate costs in real-time:

```python
class CostTracker:
    """Track token usage and costs for agent runs."""
    
    # Model pricing (2024-2025, approximate)
    PRICING = {
        "gpt-4o": {
            "input": 2.50 / 1_000_000,  # $2.50 per million input tokens
            "output": 10.00 / 1_000_000,  # $10.00 per million output tokens
        },
        "gpt-4o-mini": {
            "input": 0.15 / 1_000_000,
            "output": 0.60 / 1_000_000,
        },
        "gpt-4-turbo": {
            "input": 10.00 / 1_000_000,
            "output": 30.00 / 1_000_000,
        },
        "claude-3-5-sonnet": {
            "input": 3.00 / 1_000_000,
            "output": 15.00 / 1_000_000,
        }
    }
    
    def __init__(self, model: str = "gpt-4o", budget: float = 1.0):
        self.model = model
        self.budget = budget
        self.total_input_tokens = 0
        self.total_output_tokens = 0
        self.spent = 0.0
        self.request_count = 0
        self.cost_history = []
    
    def track_request(self, input_tokens: int, output_tokens: int):
        """Track a single request's token usage."""
        if self.model not in self.PRICING:
            # Default pricing if model not found
            input_cost = (input_tokens / 1_000_000) * 2.50
            output_cost = (output_tokens / 1_000_000) * 10.00
        else:
            pricing = self.PRICING[self.model]
            input_cost = (input_tokens / 1_000_000) * pricing["input"]
            output_cost = (output_tokens / 1_000_000) * pricing["output"]
        
        cost = input_cost + output_cost
        
        self.total_input_tokens += input_tokens
        self.total_output_tokens += output_tokens
        self.spent += cost
        self.request_count += 1
        
        self.cost_history.append({
            "input_tokens": input_tokens,
            "output_tokens": output_tokens,
            "cost": cost,
            "timestamp": time.time()
        })
    
    def can_proceed(self, estimated_additional_cost: float = 0.0) -> Tuple[bool, str]:
        """Check if agent can continue given budget constraints."""
        total_estimated = self.spent + estimated_additional_cost
        
        if total_estimated >= self.budget:
            return False, f"Budget exceeded: ${self.spent:.4f} spent, ${total_estimated:.4f} estimated"
        
        remaining = self.budget - self.spent
        if remaining < 0.01:  # Less than 1 cent
            return False, f"Budget nearly exhausted: ${remaining:.4f} remaining"
        
        return True, f"Budget OK: ${remaining:.4f} remaining"
    
    def get_stats(self) -> Dict:
        """Get cost tracking statistics."""
        return {
            "model": self.model,
            "budget": self.budget,
            "spent": self.spent,
            "remaining": self.budget - self.spent,
            "total_input_tokens": self.total_input_tokens,
            "total_output_tokens": self.total_output_tokens,
            "total_tokens": self.total_input_tokens + self.total_output_tokens,
            "request_count": self.request_count,
            "avg_cost_per_request": self.spent / self.request_count if self.request_count > 0 else 0,
            "avg_tokens_per_request": (self.total_input_tokens + self.total_output_tokens) / self.request_count if self.request_count > 0 else 0
        }
```

## Error Handling and Resilience

Production agents must handle failures gracefully and recover when possible.

### Tool Failure Handling

```python
import time
from typing import Optional, Dict, Any
import random

class RobustToolExecutor:
    """Execute tools with retries, error handling, and resilience."""
    
    def __init__(
        self,
        max_retries: int = 3,
        initial_backoff: float = 0.5,
        max_backoff: float = 5.0,
        timeout: float = 30.0
    ):
        self.max_retries = max_retries
        self.initial_backoff = initial_backoff
        self.max_backoff = max_backoff
        self.timeout = timeout
        self.tool_failures = {}
    
    def execute_with_retry(
        self,
        tool_name: str,
        tool_func: callable,
        args: dict,
        retryable_errors: List[str] = None
    ) -> Dict[str, Any]:
        """Execute tool with retry logic."""
        if retryable_errors is None:
            retryable_errors = ["timeout", "rate_limit", "network_error", "service_unavailable"]
        
        last_error = None
        
        for attempt in range(self.max_retries):
            try:
                # Execute tool (in production, add timeout handling)
                result = tool_func(**args)
                
                # Reset failure count on success
                if tool_name in self.tool_failures:
                    del self.tool_failures[tool_name]
                
                return {
                    "success": True,
                    "result": result,
                    "attempts": attempt + 1,
                    "error": None
                }
            
            except Exception as e:
                error_str = str(e).lower()
                last_error = str(e)
                
                # Check if error is retryable
                is_retryable = any(err in error_str for err in retryable_errors)
                
                if not is_retryable or attempt == self.max_retries - 1:
                    # Non-retryable error or final attempt
                    self._track_failure(tool_name)
                    return {
                        "success": False,
                        "result": None,
                        "attempts": attempt + 1,
                        "error": last_error,
                        "retryable": is_retryable
                    }
                
                # Exponential backoff
                backoff = min(
                    self.initial_backoff * (2 ** attempt),
                    self.max_backoff
                )
                # Add jitter
                backoff += random.uniform(0, 0.1 * backoff)
                
                time.sleep(backoff)
        
        self._track_failure(tool_name)
        return {
            "success": False,
            "result": None,
            "attempts": self.max_retries,
            "error": f"Max retries ({self.max_retries}) exceeded: {last_error}",
            "retryable": True
        }
    
    def _track_failure(self, tool_name: str):
        """Track tool failures for monitoring."""
        if tool_name not in self.tool_failures:
            self.tool_failures[tool_name] = 0
        self.tool_failures[tool_name] += 1
    
    def get_failure_stats(self) -> Dict[str, int]:
        """Get tool failure statistics."""
        return self.tool_failures.copy()
```

## Monitoring and Observability

Production agents need comprehensive monitoring to understand behavior and debug issues.

### Agent Metrics

Track key metrics for agent runs:

```python
import time
from typing import Dict, List
from datetime import datetime

class AgentMetrics:
    """Collect and track agent metrics."""
    
    def __init__(self):
        self.run_id = None
        self.start_time = None
        self.end_time = None
        self.iterations = 0
        self.tool_calls = []
        self.tokens_used = {"input": 0, "output": 0}
        self.errors = []
        self.final_status = None
    
    def start_run(self, run_id: str, task: str):
        """Start tracking a new agent run."""
        self.run_id = run_id
        self.start_time = time.time()
        self.end_time = None
        self.iterations = 0
        self.tool_calls = []
        self.tokens_used = {"input": 0, "output": 0}
        self.errors = []
        self.final_status = None
        self.task = task
    
    def record_iteration(self, iteration_data: Dict):
        """Record data for an iteration."""
        self.iterations += 1
        if "tool_call" in iteration_data:
            self.tool_calls.append({
                "iteration": self.iterations,
                "tool": iteration_data["tool_call"],
                "timestamp": time.time()
            })
        if "tokens" in iteration_data:
            self.tokens_used["input"] += iteration_data["tokens"].get("input", 0)
            self.tokens_used["output"] += iteration_data["tokens"].get("output", 0)
    
    def record_error(self, error: str, context: Dict = None):
        """Record an error."""
        self.errors.append({
            "error": error,
            "context": context,
            "iteration": self.iterations,
            "timestamp": time.time()
        })
    
    def end_run(self, status: str, result: Any = None):
        """End tracking for a run."""
        self.end_time = time.time()
        self.final_status = status
        self.result = result
    
    def get_metrics(self) -> Dict:
        """Get all metrics for the run."""
        duration = (self.end_time or time.time()) - (self.start_time or time.time())
        
        return {
            "run_id": self.run_id,
            "task": self.task,
            "status": self.final_status,
            "duration_seconds": duration,
            "iterations": self.iterations,
            "tokens_used": self.tokens_used.copy(),
            "total_tokens": self.tokens_used["input"] + self.tokens_used["output"],
            "tool_calls": len(self.tool_calls),
            "tool_call_details": self.tool_calls.copy(),
            "errors": len(self.errors),
            "error_details": self.errors.copy(),
            "success_rate": 1.0 if len(self.errors) == 0 else max(0, 1.0 - (len(self.errors) / self.iterations)),
            "start_time": datetime.fromtimestamp(self.start_time).isoformat() if self.start_time else None,
            "end_time": datetime.fromtimestamp(self.end_time).isoformat() if self.end_time else None
        }
```

## Common Mistakes

### 1. No loop prevention

Deploying agents without loop prevention leads to infinite runs, massive costs, and system failures.

**Problems:**
- Agents run indefinitely
- Token costs explode
- System resources exhausted
- Poor user experience

**Solutions:**
- Always set max_iterations (10-20 typical)
- Set max_execution_time (e.g., 5 minutes)
- Implement repetition detection
- Detect circular patterns
- Track progress

Never deploy agents without loop prevention. It's not optional.

### 2. No cost tracking or budgets

Without cost tracking, agent runs can cost hundreds or thousands of dollars unexpectedly.

**Problems:**
- No visibility into costs
- Budget overruns
- Unexpected bills
- Can't optimize costs

**Solutions:**
- Track tokens for every request
- Calculate costs in real-time
- Set per-run budgets
- Alert on high costs
- Monitor cost trends

Set budgets aggressively - it's better to fail fast than spend $1000 on a single run.

### 3. Poor error handling

Agents that crash on first error provide poor user experience and aren't production-ready.

**Problems:**
- Single tool failure stops agent
- No retry logic
- Errors not communicated to users
- No error recovery

**Solutions:**
- Retry transient errors (timeouts, rate limits)
- Handle tool failures gracefully
- Return errors to LLM for adaptation
- Log all errors for debugging
- Implement circuit breakers for failing tools

Production agents must be resilient to failures.

### 4. No monitoring or observability

Without monitoring, you can't understand agent behavior, debug issues, or improve performance.

**Problems:**
- Can't debug production issues
- No visibility into token usage
- Can't identify bottlenecks
- No metrics on success/failure rates

**Solutions:**
- Log all agent decisions
- Track tool usage and success rates
- Monitor token consumption
- Track execution times
- Record errors and failures
- Use tools like LangSmith, Weights & Biases, or custom logging

You can't improve what you don't measure.

### 5. No conversation management

Long conversation histories consume massive tokens and degrade performance.

**Problems:**
- Token costs grow linearly with conversation length
- Context window limits reached
- Performance degrades with long histories
- Can't handle long-running conversations

**Solutions:**
- Summarize conversation history
- Keep only recent messages
- Implement sliding window
- Use external state storage
- Clear irrelevant context

For long conversations, summarize early and often.

### 6. No timeout handling

Agents can hang indefinitely waiting for tools or LLM responses.

**Problems:**
- Tools hang without timeouts
- Users wait indefinitely
- Resources locked up
- Poor user experience

**Solutions:**
- Set timeouts for all tool executions
- Set timeouts for LLM calls
- Use async execution with timeouts
- Cancel long-running operations
- Return timeout errors gracefully

Every external call needs a timeout.

### 7. Ignoring tool failure patterns

Repeated tool failures indicate systemic issues that need attention.

**Problems:**
- Same tool fails repeatedly
- No alerting on failure patterns
- Can't identify problematic tools
- Users experience consistent failures

**Solutions:**
- Track tool failure rates
- Alert on high failure rates
- Implement circuit breakers
- Disable failing tools temporarily
- Investigate root causes

Monitor tool health and take action on patterns.

### 8. No testing with edge cases

Testing only with happy paths misses production failures.

**Problems:**
- Edge cases cause production failures
- Unexpected behavior in production
- Poor error handling revealed late
- Difficult to debug

**Solutions:**
- Test with impossible tasks
- Test with failing tools
- Test with budget limits
- Test with network failures
- Test with invalid inputs
- Test with long-running tasks

Test edge cases aggressively - they will happen in production.

### 9. Not optimizing token usage

Inefficient prompt design and conversation management wastes tokens and money.

**Problems:**
- Unnecessary tokens in prompts
- No conversation summarization
- Verbose tool descriptions
- Redundant context

**Solutions:**
- Optimize prompt length
- Summarize conversations
- Keep tool descriptions concise
- Remove redundant context
- Use cheaper models when possible
- Monitor and optimize token usage

Token optimization directly reduces costs.

### 10. Deploying without gradual rollout

Deploying new agents to all users immediately risks widespread failures.

**Problems:**
- Bugs affect all users
- Cost issues impact entire system
- Difficult to rollback
- No ability to compare performance

**Solutions:**
- Start with small percentage of traffic
- Gradually increase rollout
- Monitor metrics at each stage
- Compare old vs new performance
- Have rollback plan ready

Always roll out gradually and monitor closely.
