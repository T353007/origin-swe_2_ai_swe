# AI Agent Architectures

## Overview

AI agents are systems that can reason, plan, and use tools to accomplish complex tasks. Understanding different agent architectures helps you build effective agents for your use cases.

## Main Content

### What Are AI Agents?

Agents are LLM-powered systems that:
- **Reason** about tasks and break them into steps
- **Plan** their approach to solving problems
- **Use tools** to interact with external systems
- **Iterate** based on tool outputs until the task is complete

### Agent Architectures

#### 1. ReAct (Reasoning + Acting)

ReAct agents alternate between reasoning and taking actions:

```
Thought: I need to search for information about RAG
Action: search
Action Input: "What is RAG in AI?"
Observation: RAG is Retrieval-Augmented Generation...
Thought: Now I have the information, I can answer the question
Action: final_answer
Action Input: "RAG is Retrieval-Augmented Generation..."
```

**Pros**: Simple, works well for many tasks
**Cons**: Can get stuck in loops, limited planning

#### 2. Plan-and-Execute

Agent first creates a plan, then executes it:

```
Plan:
1. Search for information about RAG
2. Extract key concepts
3. Format answer

Execution:
Step 1: search("RAG")
Step 2: extract_concepts(...)
Step 3: format_answer(...)
```

**Pros**: Better for complex multi-step tasks
**Cons**: Plan may become outdated, more complex

#### 3. ReWOO (Relevant Object)

Advanced architecture that uses object decomposition for better planning.

### Building a Simple Agent

```python
from langchain_openai import ChatOpenAI
from langchain.agents import create_openai_tools_agent, AgentExecutor
from langchain_core.tools import Tool
from langchain_core.prompts import ChatPromptTemplate

llm = ChatOpenAI(model="gpt-4", temperature=0)

# Define tools
def search(query: str) -> str:
    # Your search implementation
    return "Search results..."

def calculator(expression: str) -> str:
    try:
        result = eval(expression)
        return str(result)
    except:
        return "Invalid expression"

tools = [
    Tool(
        name="Search",
        func=search,
        description="Search for information"
    ),
    Tool(
        name="Calculator",
        func=calculator,
        description="Perform calculations"
    )
]

# Create agent
prompt = ChatPromptTemplate.from_messages([
    ("system", "You are a helpful assistant"),
    ("human", "{input}"),
    ("placeholder", "{agent_scratchpad}")
])

agent = create_openai_tools_agent(llm, tools, prompt)
agent_executor = AgentExecutor(agent=agent, tools=tools, verbose=True)

# Use agent
result = agent_executor.invoke({"input": "What is 25 * 4? Then search for information about RAG."})
```

## Common Mistakes

1. **Infinite loops**: No max iterations or loop detection
2. **Wrong tool descriptions**: Agent can't choose correct tools
3. **No error handling**: Tool failures crash the agent
4. **Too many tools**: Agent gets confused with too many options
5. **No planning**: Complex tasks need planning, not just ReAct
6. **Token blowups**: Long agent runs consume many tokens
