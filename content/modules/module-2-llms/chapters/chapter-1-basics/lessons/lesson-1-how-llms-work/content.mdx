# How LLMs Work (High-Level)

## Overview

Understanding how LLMs work at a high level helps you use them effectively. You don't need deep ML knowledge, but understanding the basics improves your engineering decisions.

## Main Content

### What Are LLMs?

Large Language Models are neural networks trained on massive text corpora to predict the next token in a sequence. They learn patterns, grammar, facts, and reasoning from training data.

### Key Concepts

**Tokens**: LLMs process text as tokens (words or sub-words)

**Context Window**: Maximum tokens the model can consider at once

**Attention Mechanism**: Allows models to focus on relevant parts of input

**Temperature**: Controls randomness in output (covered in Module 1)

**Probabilistic Outputs**: Same input can produce different outputs

## Code Examples

Understanding tokenization:

```python
import tiktoken

encoding = tiktoken.encoding_for_model("gpt-4")
text = "Hello, world!"
tokens = encoding.encode(text)

print(f"Text: {text}")
print(f"Tokens: {tokens}")
print(f"Decoded: {encoding.decode(tokens)}")
```

## Common Mistakes

1. **Expecting deterministic outputs**: LLMs are probabilistic
2. **Ignoring context limits**: Models have token limits
3. **Not understanding tokenization**: Leads to unexpected costs
4. **Assuming factual accuracy**: LLMs can hallucinate
