# Structured Outputs

## Overview

LLMs typically return free-form text, but many applications need structured data (JSON, XML, etc.). This lesson covers techniques for getting reliable structured outputs.

## Main Content

### JSON Mode

OpenAI supports JSON mode for guaranteed JSON output:

```python
from openai import OpenAI
import json

client = OpenAI()

response = client.chat.completions.create(
    model="gpt-4",
    messages=[{
        "role": "user",
        "content": "Extract information as JSON: name, age, location"
    }],
    response_format={"type": "json_object"}
)

result = json.loads(response.choices[0].message.content)
```

### Prompt Engineering for Structure

Use clear instructions and examples:

```python
prompt = """Extract information from this text and return as JSON.

Text: John is 30 years old and lives in San Francisco.

Format:
{
  "name": "string",
  "age": number,
  "location": "string"
}

JSON:"""
```

### Function Calling for Structure

Use function calling to get structured output:

```python
schema = {
    "type": "object",
    "properties": {
        "name": {"type": "string"},
        "age": {"type": "number"},
        "location": {"type": "string"}
    },
    "required": ["name", "age", "location"]
}

functions = [{
    "name": "extract_info",
    "description": "Extract structured information",
    "parameters": schema
}]

response = client.chat.completions.create(
    model="gpt-4",
    messages=[{"role": "user", "content": "Extract: John, 30, San Francisco"}],
    functions=functions
)

# Parse from function_call.arguments
data = json.loads(response.choices[0].message.function_call.arguments)
```

## Code Examples

Robust structured output:

```python
from pydantic import BaseModel, ValidationError
import json

class PersonInfo(BaseModel):
    name: str
    age: int
    location: str

def extract_structured(text: str) -> PersonInfo:
    """Extract structured data with validation."""
    prompt = f"""Extract person information as JSON:
{text}

Return JSON with name, age, location."""
    
    response = client.chat.completions.create(
        model="gpt-4",
        messages=[{"role": "user", "content": prompt}],
        response_format={"type": "json_object"}
    )
    
    try:
        data = json.loads(response.choices[0].message.content)
        return PersonInfo(**data)  # Validates with Pydantic
    except (json.JSONDecodeError, ValidationError) as e:
        # Retry or handle error
        raise ValueError(f"Failed to extract structured data: {e}")
```

## Common Mistakes

1. **No validation**: Trusting LLM output structure
2. **Parsing errors**: Not handling malformed JSON
3. **No retries**: Single attempt may fail
4. **Unclear prompts**: LLM doesn't understand format needed
