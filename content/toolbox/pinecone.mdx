# Pinecone

Pinecone is a managed vector database designed for production AI applications. As of December 2025, it offers both serverless and dedicated options, making it a popular choice for companies that need a scalable, managed solution for vector search without managing infrastructure.

## Overview

Pinecone provides a fully managed vector database service:
- **Managed Service**: Fully managed infrastructure, no DevOps required
- **Serverless Option**: Serverless deployment for automatic scaling
- **Dedicated Option**: Dedicated clusters for high-performance applications
- **Global Distribution**: Deploy indexes across multiple regions
- **High Performance**: Optimized for fast similarity search at scale
- **Simple API**: Clean, RESTful API with official Python, Node.js, and Go clients

## When to Use

- Production RAG applications requiring high availability
- Large-scale applications with millions of vectors
- Need managed infrastructure without DevOps overhead
- Serverless architecture requirements
- Global applications needing multi-region deployment
- When you need fast, reliable vector search without infrastructure management

## Key Features (As of December 2025)

- **Serverless and Dedicated**: Choose between serverless (pay-per-use) or dedicated (high-performance) options
- **Managed Infrastructure**: Fully managed, no infrastructure to maintain
- **Global Deployment**: Deploy indexes across multiple regions
- **High Performance**: Optimized for fast similarity search
- **Metadata Filtering**: Filter results by metadata attributes
- **Namespaces**: Organize vectors into namespaces for multi-tenancy
- **Python/Node.js SDKs**: Official SDKs for popular languages
- **LangChain Integration**: Native integration with LangChain
- **LlamaIndex Integration**: Native integration with LlamaIndex

## Basic Example

```python
from pinecone import Pinecone, ServerlessSpec
from openai import OpenAI

# Initialize Pinecone client
pc = Pinecone(api_key="your-api-key")

# Create index (serverless)
pc.create_index(
    name="documents",
    dimension=1536,  # Dimension of your embeddings (e.g., text-embedding-3-small)
    metric="cosine",
    spec=ServerlessSpec(
        cloud="aws",
        region="us-east-1"
    )
)

# Get index
index = pc.Index("documents")

# Generate embeddings
openai_client = OpenAI()
embedding = openai_client.embeddings.create(
    model="text-embedding-3-small",
    input="What is RAG?"
).data[0].embedding

# Upsert vectors
index.upsert(
    vectors=[
        {
            "id": "doc1",
            "values": embedding,
            "metadata": {"text": "What is RAG?", "source": "faq"}
        }
    ]
)

# Query
results = index.query(
    vector=embedding,
    top_k=5,
    include_metadata=True
)
```

## LlamaIndex Integration Example

```python
from llama_index.core import VectorStoreIndex, StorageContext
from llama_index.vector_stores.pinecone import PineconeVectorStore
from llama_index.embeddings.openai import OpenAIEmbedding
from pinecone import Pinecone

# Initialize Pinecone
pc = Pinecone(api_key="your-api-key")
pinecone_index = pc.Index("documents")

# Create vector store
vector_store = PineconeVectorStore(pinecone_index=pinecone_index)
storage_context = StorageContext.from_defaults(vector_store=vector_store)

# Create index
embed_model = OpenAIEmbedding(model="text-embedding-3-small")
index = VectorStoreIndex.from_documents(
    documents,
    storage_context=storage_context,
    embed_model=embed_model
)

# Query
query_engine = index.as_query_engine()
response = query_engine.query("What is RAG?")
```

## Metadata Filtering Example

```python
from pinecone import Pinecone

pc = Pinecone(api_key="your-api-key")
index = pc.Index("documents")

# Query with metadata filtering
results = index.query(
    vector=query_vector,
    top_k=10,
    filter={
        "category": {"$eq": "technical"},
        "year": {"$gte": 2024}
    },
    include_metadata=True
)

# Complex filters
results = index.query(
    vector=query_vector,
    top_k=10,
    filter={
        "$and": [
            {"category": {"$eq": "technical"}},
            {"year": {"$gte": 2024}}
        ]
    }
)
```

## Production Best Practices

1. **Choose Right Option**: Use serverless for variable traffic, dedicated for consistent high performance
2. **Index Dimensions**: Ensure dimension matches your embedding model (e.g., 1536 for text-embedding-3-small)
3. **Metadata Design**: Design metadata schemas for efficient filtering
4. **Namespaces**: Use namespaces for multi-tenancy and data isolation
5. **Monitoring**: Monitor index size, query latency, and costs
6. **Error Handling**: Implement retry logic and error handling
7. **Cost Optimization**: Monitor usage and optimize for cost (serverless vs dedicated)
8. **Backup Strategy**: Implement backup strategies for critical data
