# LlamaIndex

LlamaIndex is a data framework that provides production-ready tools for connecting custom data sources to LLMs. As of December 2025, it's a popular choice for building RAG applications with advanced indexing, querying, and data integration capabilities.

## Overview

LlamaIndex excels at data ingestion and RAG workflows by providing:
- **Data Connectors**: 100+ connectors for various data sources
- **Indexing**: Multiple indexing strategies (vector, tree, keyword)
- **Querying**: Advanced query engines with transformations and reranking
- **Agents**: Data-aware agents that can query and reason over data
- **Structured Data**: Native support for SQL, JSON, and structured data
- **Evaluation**: Built-in evaluation frameworks for RAG systems

## When to Use

- Building RAG applications with complex data sources
- Ingesting data from multiple formats and sources
- Need advanced query transformations (sub-questions, query rewriting)
- Working with structured data (SQL databases, JSON APIs)
- Building data agents that reason over knowledge bases
- Applications requiring hybrid search (vector + keyword)

## Key Features (As of December 2025)

- **100+ Data Connectors**: PDF, SQL databases, APIs, vector databases, and more
- **Advanced Indexing**: Vector stores, tree indices, keyword indices, document stores
- **Query Engines**: Multiple query engines with transformations, reranking, and filtering
- **Reranking**: Integration with reranking models for improved relevance
- **Structured Data**: Native support for SQL databases and structured outputs
- **Agent Framework**: Data-aware agents with tool calling
- **Streaming**: Support for streaming responses
- **Observability**: Built-in tracing and monitoring capabilities

## Basic Example

```python
from llama_index.core import VectorStoreIndex, SimpleDirectoryReader
from llama_index.llms.openai import OpenAI
from llama_index.embeddings.openai import OpenAIEmbedding

# Initialize LLM and embeddings (as of December 2025)
llm = OpenAI(model="gpt-4o", temperature=0)
embed_model = OpenAIEmbedding(model="text-embedding-3-small")

# Load and index documents
documents = SimpleDirectoryReader("./data").load_data()
index = VectorStoreIndex.from_documents(
    documents,
    embed_model=embed_model
)

# Create query engine
query_engine = index.as_query_engine(llm=llm)

# Query
response = query_engine.query("What is RAG?")
print(response)
```

## Advanced Query Example with Reranking

```python
from llama_index.core import VectorStoreIndex
from llama_index.postprocessor import CohereRerank
from llama_index.query_engine import RetrieverQueryEngine
from llama_index.retrievers import VectorIndexRetriever

# Create index (assuming already created)
index = VectorStoreIndex.from_documents(documents, embed_model=embed_model)

# Configure retriever
retriever = VectorIndexRetriever(
    index=index,
    similarity_top_k=20  # Retrieve more initially
)

# Add reranking
reranker = CohereRerank(api_key=os.getenv("COHERE_API_KEY"), top_n=5)

# Create query engine with reranking
query_engine = RetrieverQueryEngine.from_args(
    retriever=retriever,
    node_postprocessors=[reranker],
    llm=llm
)

response = query_engine.query("What are the main benefits of RAG?")
print(response)
```

## SQL Query Example

```python
from llama_index.core import SQLDatabase
from llama_index.core.query_engine import NLSQLTableQueryEngine
from sqlalchemy import create_engine

# Connect to SQL database
engine = create_engine("sqlite:///./example.db")
sql_database = SQLDatabase(engine)

# Create SQL query engine
query_engine = NLSQLTableQueryEngine(
    sql_database=sql_database,
    llm=llm
)

# Natural language query gets converted to SQL
response = query_engine.query(
    "How many users signed up in the last month?"
)
print(response)
```

## Hybrid Search Example

```python
from llama_index.core import VectorStoreIndex, StorageContext
from llama_index.vector_stores import PineconeVectorStore
from llama_index.core.query_engine import VectorStoreIndexQueryEngine

# Create hybrid query engine (combines vector and keyword search)
index = VectorStoreIndex.from_documents(
    documents,
    embed_model=embed_model,
    storage_context=StorageContext.from_defaults(
        vector_store=PineconeVectorStore(
            index_name="my-index",
            api_key=os.getenv("PINECONE_API_KEY")
        )
    )
)

# Query with hybrid search
query_engine = index.as_query_engine(
    llm=llm,
    similarity_top_k=10,
    use_hybrid=True  # Enable hybrid search
)

response = query_engine.query("Explain vector databases")
print(response)
```

## Production Best Practices

1. **Use Reranking**: Always use reranking for better relevance (Cohere, Jina, etc.)
2. **Chunking Strategy**: Choose appropriate chunk size based on your data and model
3. **Hybrid Search**: Enable hybrid search for better retrieval (vector + keyword)
4. **Metadata Filtering**: Use metadata filters for better context selection
5. **Streaming**: Use streaming for better user experience
6. **Error Handling**: Handle query failures gracefully
7. **Cost Optimization**: Monitor token usage and optimize chunk sizes
8. **Evaluation**: Use LlamaIndex's evaluation framework to measure quality
